# Career Target

## Direção principal

Busca de oportunidades em tecnologia com preferência por posições de entrada/júnior ou compatíveis com experiência demonstrável.

## Trilhas prioritárias iniciais

1. Desenvolvedor Full Stack Júnior
2. Desenvolvedor .NET / C# / Blazor
3. Python Developer Júnior
4. Desenvolvimento web / APIs REST
5. Suporte Técnico com perfil analítico e conhecimento de APIs, JSON, logs e SQL

## Competências já exploradas em projetos/estudos

- C#
- .NET
- Blazor
- Python
- JavaScript
- HTML
- CSS / Bootstrap
- Node.js
- Express
- APIs REST
- JSON
- SQL
- MySQL
- SQL Server
- Git / GitHub
- Linux
- modelagem e fundamentos de banco de dados

## Estratégia

Priorizar vagas em que projetos reais e formação consigam demonstrar competência, mesmo quando a experiência profissional formal em desenvolvimento ainda estiver em construção.

Não apresentar competência como domínio avançado sem evidência.

## Posicionamento

Mostrar capacidade prática, evolução técnica, resolução de problemas e projetos concretos. Evitar frases genéricas como "apaixonado por tecnologia" quando uma evidência real puder ocupar o lugar.
