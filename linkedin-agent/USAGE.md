# Uso no ChatGPT

Este repositorio funciona como fonte de instrucoes para o agente. O ChatGPT conectado ao GitHub pode ler os arquivos e executar o fluxo correspondente.

Exemplos:

- `LinkedIn Agent: analisa esta vaga: <link ou texto>`
- `LinkedIn Agent: ajusta meu perfil para vagas .NET junior`
- `LinkedIn Agent: prepara minha candidatura para esta vaga`
- `LinkedIn Agent: transforme o projeto <repo> em descricao para LinkedIn`
- `LinkedIn Agent: me prepare para a entrevista desta vaga`
- `LinkedIn Agent: organize minha semana de candidaturas`

O agente prepara o trabalho, mas nao automatiza acoes na interface do LinkedIn.
