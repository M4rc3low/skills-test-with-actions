# linkedin-tracker

Manter historico de candidaturas para evitar perda de contexto e melhorar decisoes futuras.

## Campos

id, empresa, cargo, url, data_encontrada, data_aplicacao, modalidade, local, faixa_salarial, score_compatibilidade, status, contato_recrutador, proxima_acao, data_followup, observacoes.

## Status

encontrada, analisada, aplicada, recrutador_contatado, entrevista_rh, entrevista_tecnica, desafio, proposta, rejeitada, encerrada.

## Regra

Somente registrar como aplicada quando o usuario confirmar que a candidatura foi enviada.
