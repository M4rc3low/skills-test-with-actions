# linkedin-post

Transformar aprendizado e projetos reais em conteudo profissional que fortalece empregabilidade.

## Fontes prioritarias

Projeto concluido, bug resolvido, decisao tecnica, aprendizado de curso, laboratorio, certificacao ou comparacao entre abordagens.

## Estrutura

1. primeira linha concreta
2. contexto
3. problema
4. o que foi feito
5. aprendizado
6. fechamento simples

## Regras

Uma ideia por post. Preferir evidencias a adjetivos. Evitar frases feitas. Nao inventar metricas. Nao publicar automaticamente.
