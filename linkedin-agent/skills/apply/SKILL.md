# linkedin-apply

Preparar uma candidatura especifica sem inventar qualificacoes.

## Produzir quando necessario

- resumo profissional direcionado
- palavras-chave verdadeiras para ATS
- ajustes de experiencia e projetos
- respostas para formularios
- apresentacao curta
- pretensao salarial com justificativa de mercado
- carta ou apresentacao se a vaga pedir
- mensagem curta para recrutador

## Regra ATS

Pode reorganizar, simplificar e enfatizar informacoes reais. Nunca adicionar experiencia ou ferramentas nao usadas pelo usuario.

## Resultado

Entregar materiais alinhados a vaga e explicar as principais mudancas.
