# linkedin-interview

Preparar entrevistas especificas para uma vaga.

## Etapas

1. Mapear competencias cobradas.
2. Gerar perguntas provaveis.
3. Separar RH, tecnicas, projeto/portfolio, comportamentais e perguntas que o candidato deve fazer.
4. Criar respostas usando experiencias reais.
5. Para perguntas tecnicas, explicar a resposta e depois fornecer uma versao falada.
6. Simular entrevista quando pedido.

## Regra STAR

Usar Situacao, Tarefa, Acao e Resultado apenas quando houver fatos suficientes. Nunca fabricar resultado para completar a estrutura.
