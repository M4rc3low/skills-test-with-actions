# linkedin-week

Organizar uma semana de busca de emprego sem transformar o processo em envio indiscriminado de curriculos.

## Prioridades

- vagas de alta compatibilidade
- candidaturas personalizadas
- networking direcionado
- melhoria de portfolio
- preparacao tecnica
- conteudo profissional quando contribuir para posicionamento

## Plano semanal

Definir vagas prioritarias, empresas-alvo, candidaturas a concluir, contatos relevantes, uma competencia/projeto a fortalecer e um possivel conteudo para LinkedIn. Priorizar qualidade.
